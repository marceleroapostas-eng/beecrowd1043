# Beecrowd 1043 - Triângulo



## Descrição



Este programa resolve o problema 1043 do Beecrowd.



## Tecnologias utilizadas



- Java

- NetBeans

- Maven



## Entrada



A entrada contém três valores reais A, B e C.



## Saída



O programa apresenta o perímetro do triângulo caso os valores possam formar um triângulo.



Caso contrário, apresenta a área do trapézio formado por A e B como bases e C como altura.
